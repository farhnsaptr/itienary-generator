# Modul Frontend: Activities & Activity Photos

Modul ini bertanggung jawab untuk visualisasi jadwal kegiatan perjalanan dalam bentuk **Linear Timeline Scrapbook**, penambahan jadwal kegiatan baru, pengambilan/pengunggahan foto via kamera perangkat (`capture="environment"`), serta tampilan modal galeri foto berbentuk **cetakan polaroid lucu** (mendukung *swipe* mobile dan *arrow* desktop).
